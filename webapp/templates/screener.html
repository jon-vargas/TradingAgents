Discover Tickers

Hopper — listing check is not a buy signal. Momentum chips find names; rank them with Scan mode → Early momentum (Scan All → Momentum tab). Other families use Screen (Opportunity) with the Book preset.

How this hopper works

Momentum templates are cap-split: Micro ($25M–$300M), Small-cap ($500M–$2B), Mid-cap ($2B–$8B). Perplexity proposes names; Yahoo validates listing and cap band. Hopper flags (gates, P-buy, event, runway) are hints — not score_final. For ranked momentum: add New names to a watchlist, set Scan mode → Early momentum, then Scan All and open the Momentum tab. Non-momentum families: keep New listed names and use Screen (Opportunity) with the Book preset.
